campspot-bot

Watches Upper Pines Campground (rec.gov id 232447) for Thu–Sun stays through Sep 30, and (optionally) drives a real Chrome to add the slot to your cart so the 15-minute hold protects it while you check out.

1. Architecture

CampspotChecker

Hits the public availability API every pollIntervalMs. Merges multiple months. Memorizes stays it's already seen so the same opening doesn't fire twice. 
GET .../api/camps/availability/
   campground/232447/month
   ?start_date=2026-07-01T00:00:00Z
→

findStays

Pure date logic. Walks each campsite's daily map and emits consecutive runs of Available nights that fall entirely on Thu/Fri/Sat/Sun, capped at 4 nights. Ranks longest → earliest. 
stay = { siteNo, startDate,
         endDate, nights }
→

CampspotCartBot

Playwright-driven Chromium that re-uses the rec.gov session you logged in with via permit-bot. Clicks the Available cell, then Add to Cart, then verifies /cart. 
page.click('[aria-label=
  "Jul 9, 2026 - Site 068
   is available"]')

2. What counts as a "stay"

A stay is the longest contiguous run of Available nights within Thu–Sun, capped at 4. Each run also gets sliced so no run exceeds the cap.

  • Mon/Tue/Wed break the run automatically — they're not in targetWeekdays.
  • Reserved, Closed, and missing entries break the run.
  • Ranking: most nights first, then earliest start, then lowest site number.
  • Dedup: a stay only fires once per "open period." If it closes & reopens, it fires again.

3. Poll loop (every pollIntervalMs)

+0ms
Fetch each month in the configured window (one HTTP request per month).
+~400ms
Merge months → findAllStays → rankStays.
Compare against lastSeenStays. Anything not seen since last poll is new.
on new
Discord push: {header, bullets per stay, booking URLs}. ntfy push with tap-action to the rec.gov page.
on new + --auto-grab
Fire CampspotCartBot on the top-ranked new stay (one at a time; 1-hour cooldown per (site, dates) so we don't retry the same loss).
on 429 / 5xx
Exponential backoff up to 5 min. Honors Retry-After. Stops hammering the API.
sleep
Wait pollIntervalMs minus elapsed, plus backoff. Repeat.

4. The cart automation, step by step

  1. Open https://www.recreation.gov/camping/campgrounds/232447?startdate=<X>&enddate=<Y> in a headed Chromium (same profile as permit-bot so the rec.gov cookie carries over).
  2. If a re-auth modal pops, fill it via handleLoginModalIfPresent from permit-bot.
  3. Advance the calendar via button[aria-label="Go Forward 5 Days"] until the target date column is in the grid (up to 60 advances ≈ 300 days).
  4. Locate the cell:
    [aria-label="Sep 11, 2026 - Site 068 is available" i]
  5. Click it. A single click is enough because the page derives the trip range from the URL params.
  6. Click #add-cart-campsite ("Add to Cart"). Re-runs the login-modal handler in case rec.gov demands a fresh auth.
  7. Open /cart in a fresh tab. Verify body text contains Site <N> AND the start date. Screenshot.
  8. Post outcome to Discord with the cart screenshot attached.

If the cell isn't found after the calendar advances, the bot exits with cell_not_available instead of clicking blindly — the slot was taken between the API poll and the click.

5. Run modes

CommandWhat happens
check One-shot scan. Prints every qualifying stay (sorted). No browser, no notifications. safe, read-only
cart --site=068 --start=… --end=… Dry-run. Opens Chromium, advances calendar, locates the cell, screenshots. Does NOT click Add to Cart. safe
cart … --for-real Same flow, but clicks Add to Cart and verifies the hold. creates a real 15-min hold
watch Polls forever. Discord/ntfy on new openings. No cart. recommended start mode
watch --auto-grab Polls forever. On a new opening, fires --for-real automatically on the top-ranked stay. creates real holds
release-cart Test cleanup. Clicks every Remove button on /cart.

6. Config knobs (campspot-bot/config.json)

{
  "campgroundId": "232447",            // Upper Pines
  "rangeStartDate": "2026-06-22",      // window inclusive
  "rangeEndDate":   "2026-09-30",
  "targetWeekdays": ["Thu","Fri","Sat","Sun"],
  "maxNights": 4,                      // cap on stay length
  "minNights": 1,                      // drop shorter stays (raise to 2 to skip 1-nighters)
  "pollIntervalMs": 60000,             // 60s default
  "autoCart": false                    // informational; CLI flag controls the actual mode
}
